## C. Сценарии планирования

### C1. Один склад, утро + день

- [ ] Склад: первая загрузка `07:00-09:00`, дозагрузка 1 `12:00-13:00`.
- [ ] Курьер: `max_runs` = 2.
- [ ] Заказ A — партия «Утро», заказ B — «День».
- [ ] Экспорт: у A `depot_ready_time` пустой или от настройки «Утро»; у B — `12:00:00` (начало окна дозагрузки).
- [ ] Sidebar «Маршрут»: строка партий вида `Утро N → День M → …` (без полного таймлайна).

### C2. Один склад, утро + день + вечер

- [ ] Дозагрузка 2 `16:00-17:00`, заказ C — «Вечер», `max_runs` = 3 (или warning при 2 с подтверждением).
- [ ] У C `depot_ready_time` ≈ `16:00:00`.

### C3. Два склада

- [ ] Склады ID `1` и `2`; заказы на разных складах.
- [ ] У курьера `allow_different_depots_in_route` = TRUE.

### C4. Своё время (custom)

- [ ] Заказ с партией «Своё время», `depot_ready_time` = `14:30:00`.
- [ ] В экспорте — именно это значение, не из окна склада.

### C5. Два custom с разным ready time

- [ ] Два заказа «Своё время»: `12:00:00` и `16:00:00`.
- [ ] При `max_runs` = 2 — warning о числе групп загрузки (3 группы: утро/день/вечер не нужны — 2 custom = 2 группы; если ещё есть утро — 3 группы).

## D. Ошибки и блокировки

- [ ] **D1.** Заказ с `depot_id`, которого нет в списке складов → экспорт **блокируется**, сообщение об ошибке.
- [ ] **D2.** Заказ без координат → экспорт блокируется.
- [ ] **D3.** Склад с **двумя** окнами дозагрузки → `time_windows_refilling.time_windows.0.time_window` и `.1.time_window`.
- [ ] **D4.** `max_runs` меньше числа групп загрузки → warning, можно отменить или подтвердить.

## F. Импорт в Яндекс (типичные ошибки)

| Симптом в Яндексе | Причина | Исправление в экспорте |
|-------------------|---------|------------------------|
| Неизвестный `load_service_duration_s` | Поле не поддерживается в Excel Depot | Колонка убрана из экспорта |
| Неизвестный `depot_extra_service_duration_s` | Не в шаблоне импорта Vehicles | Колонка убрана |
| `TRUE` в жёстком окне загрузки | `hard_time_window` — это интервал, не boolean | Пусто или копия окна загрузки |
| Заказ `depot:501` не найден | `start_at`/`finish_at` — ID заказа, не склад | Оставить пустым, использовать `starting_depot_id` + флаги склада |
| Options: 2 строки / не логические значения | Лишняя строка с русскими заголовками | Лист Options: 1 строка ключей + 1 строка `TRUE`/`FALSE` |
| Формат окна `12:00-13:00` | Нужен `12:00:00-13:00:00` | Автоформат при экспорте |
| `expected value of type object` для `time_windows_refilling` | Ключи `.0.time_window` дают массив, API ждёт объект с `time_windows[]` | 2+ окна → `time_windows_refilling.time_windows.0.time_window` |
| `;` в одной ячейке | Несколько интервалов в одной ячейке не поддерживаются | См. индексные колонки выше |

После обновления: заново **«Загрузить демо»** → **«Скачать XLSX»**.

## G. Быстрый демо-пример для Яндекса

1. Откройте **«Сложное планирование»**.
2. Нажмите **«Загрузить демо (Москва/МО)»** — подставится:
   - склад **501** (Лыткарино): загрузка 07:00–09:00, дозагрузки 12:00–13:00 и 16:00–17:00;
   - курьер **801**, `max_runs = 3`;
   - 8 заказов: 3 утром, 2 днём, 2 вечером, 1 «своё время» (Подольск, ready 14:30).
3. При необходимости включите опции в toolbar (`penalize_late_service` уже включён в демо).
4. **«Скачать XLSX»** → 4 листа → импорт в [Яндекс Маршрутизацию](https://yandex.ru/courier/companies/31071/depots/all/mvrp/import).

Консоль: `app.loadComplexPlannerDemo()` — то же без кнопки.

## Примечание: несколько окон дозагрузки в Excel

В API: объект `time_windows_refilling: { time_windows: [{ time_window }, …] }`. В Excel: **одно** окно — `time_windows_refilling.time_window`; **два и более** — только нужные колонки `time_windows_refilling.time_windows.0.time_window`, `.1…` (пустые слоты 2–3 не экспортируются).

**Жёлтые предупреждения в UI Яндекса** («неизвестный заголовок» для `time_windows_refilling.time_windows.N…») — ожидаемы: в официальном шаблоне Excel есть только одна колонка дозагрузки, но солвер эти ключи понимает. На маршруты не влияют. После обновления экспорта будет 2 предупреждения вместо 8 (для демо с двумя окнами).
